## License request terms

`7` (7 days Free Trial), `30` (30 days Free Trial), `365` (1 year / €25), `730` (2 years / €45), `LIFETIME` (Lifetime / €100).

The default for a new client request is `365`. The currently installed license status is separate from the term selected for a future request. A current Lifetime license therefore does not automatically change the new-request dropdown.
