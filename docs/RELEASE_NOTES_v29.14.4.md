- Firewall rule management and Network Zones.
- Application blocking and separate blocked/allowed IP views.
- Manual IPv4/IPv6 Internet Kill Switch with local/intranet scopes excluded from the rule ranges.
- Connections matrix, DNS diagnostics and LAN context.
- System Logs, Cyber Terminal and Statistics Studio.
- IP Mask as a user-interface display aid.
- English and German localized client variants.
