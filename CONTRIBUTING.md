# Contributing

Thank you for your interest in BlackIce Δ.

This repository is a public-facing product and documentation space. It contains product descriptions, screenshots, diagrams and repository policies; it does not contain the application source code or internal administration utilities.

## Documentation contributions

- Keep product claims aligned with the documented capabilities and limitations.
- Do not describe BlackIce as an independent firewall engine or packet-filter driver. Windows Defender Firewall performs traffic enforcement.
- Keep English and German product information consistent.
- Do not publish customer information, IP addresses, hardware identifiers, logs or other personal/network data in examples.
- Use screenshots from the BlackIce client and ensure sensitive information is masked before submission.

## Reporting a problem

Use a GitHub issue for visible documentation errors or broken screenshot links. Do not include credentials, license tokens, private network details or customer data.

Changes to the product itself are handled outside this public-facing documentation repository.
